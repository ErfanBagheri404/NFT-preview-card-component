# NFT preview card component

![Design preview for the NFT preview card component challenge](./design/desktop-preview.jpg)

Solution to the Frontend Mentor **NFT preview card component** challenge - a responsive component built from the provided design.

**Live demo:** https://erfan-revenant.github.io/NFT-preview-card-component/

## Built with

- Semantic HTML5
- CSS custom properties, Flexbox and media queries
- Bundled webfonts and SVG assets from the challenge starter files

## Run locally

```bash
git clone https://github.com/ErfanBagheri404/NFT-preview-card-component.git
cd NFT-preview-card-component
```

Open `index.html` in a browser. Nothing to install or compile.
